# Talentera Huddle React Preview

This folder contains the React rebuild preview for Talentera Huddle.

## Run locally

```bash
cd react-preview
npm install
npm run dev
```

The app loads the existing dashboard `data.json`, keeps HubSpot record links clickable, and includes:

- Streamlined Team Overview
- Priority lead and deal actions
- Activity and pipeline charts
- Team scoreboard
- Outreach and Rank A/B coverage
- Management brief and deal movement
- Financial page
- Detailed rep pages
- Online leads not contacted
- Offline leads not contacted
- Leads with no connected calls
- Cold, stuck, no-future-task, won, lost, and open-deal views

The existing production dashboard is not replaced. The preview is isolated under `/react-preview/`.
